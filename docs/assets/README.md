# Assets de documentación

Imágenes, diagramas y capturas usadas por los documentos de `docs/`.

- Una subcarpeta por categoría: `assets/design/`, `assets/architecture/`…
- Nombres descriptivos en kebab-case: `flujo-de-publicacion.png`.
- Preferir SVG para diagramas y capturas comprimidas para el resto: este repositorio también predica rendimiento.
- Una imagen que ya no referencia ningún documento se borra.

No usar esta carpeta para recursos del sitio (logos, favicons, fotografías del producto): esos van al directorio de assets del código fuente.
