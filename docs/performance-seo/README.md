# Rendimiento y SEO

Las dos prioridades absolutas del proyecto. Esta carpeta define los umbrales que convierten "va rápido" en algo verificable.

| Documento | Contenido |
| --- | --- |
| _(pendiente)_ `presupuesto.md` | Límites de peso de bundle, imágenes y fuentes; umbrales de Core Web Vitals |
| _(pendiente)_ `checklist-seo.md` | Metadatos, datos estructurados, sitemap, canónicas, encabezados |
| _(pendiente)_ `auditorias.md` | Resultados de Lighthouse fechados, con la regresión detectada y su causa |

## Objetivo permanente

Lighthouse **100 / 100 / 100 / 100** y **3/3** en Agentic Search. Cualquier cambio que baje una de estas cifras se trata como una regresión, no como un compromiso aceptable.

Las auditorías llevan fecha (`> Actualizado: DD-MM-AAAA`) y la versión del sitio medida; una cifra sin fecha no sirve para detectar regresiones.

**Aquí no van:** las técnicas generales de SEO — están en la skill `/seo` de [`.claude/skills/`](../../.claude/skills/). Esta carpeta guarda solo lo específico de este proyecto.
